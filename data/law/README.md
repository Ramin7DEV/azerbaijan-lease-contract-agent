# Qanun mətni

`icare.txt` — Azərbaycan Respublikası Mülki Məcəlləsinin 33-cü (Əmlak kirayəsi) və 34-cü (İcarə) fəsilləri, maddə 675–722.

- **Mənbə:** rəsmi mətn, [e-qanun.az](https://e-qanun.az) (27.09.2026 tarixində götürülüb). Rəsmi hüquqi sənəd olduğu üçün müəllif hüququ obyekti deyil.
- **Təkrar yaratmaq:** bütöv Məcəllənin DOCX-ini `data/law/mulki_mecelle.docx` kimi saxlayıb `uv run python scripts/extract_law.py` işlədin (DOCX repoya daxil deyil).
- Bu mətn hüquqi məsləhət deyil; qüvvədə olan redaksiyanı həmişə rəsmi mənbədən yoxlayın.
